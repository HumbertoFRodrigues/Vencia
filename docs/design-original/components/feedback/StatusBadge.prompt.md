The one and only way to show service state: activo (green) / a_vencer (amber) / vencido (red) / suspenso (dark) / cancelado (grey).

```jsx
<StatusBadge status="a_vencer" />
<StatusBadge status="vencido" label="Vencido há 2 dias" />
```

Use the coloured dot as the scanning cue; never use raw emoji circles in product UI.
