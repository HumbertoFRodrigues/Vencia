The system's action control — cobalt `primary` for the single main action, `secondary` for the rest, `danger` only for suspend/cancel.

```jsx
<Button variant="primary" icon="refresh-cw">Renovar</Button>
<Button>Registrar pagamento</Button>
<Button variant="danger" icon="pause">Suspender</Button>
```

Sizes: `sm` (28px, inside table rows), `md` (36px, default), `lg` (44px, forms and mobile). Labels are sentence case, imperative Portuguese verbs.
